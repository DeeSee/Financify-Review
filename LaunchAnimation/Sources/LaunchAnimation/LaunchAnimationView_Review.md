# LaunchAnimationView.swift — Code Review

## Замечания

### 1. Анимация не отменяется при удалении View
`LottieAnimationView.play { _ in onFinished() }` запускает анимацию, но если view будет удалён до завершения (например, при быстром старте), `onFinished` может вызваться для уже удалённого view.

В `FinancifyApp` это маловероятно (анимация коротка), но для робастности стоит проверить lifecycle.

### 2. `backgroundBehavior = .pauseAndRestore` (строка 35)
Если пользователь свернёт приложение во время анимации и вернётся, анимация продолжится с того же места. Это ок, но может выглядеть странно если прошло много времени.

### 3. Зависимость от внешнего пакета для launch screen
Lottie — тяжёлая зависимость (~1 MB) только для splash-анимации. Стоит оценить, оправдана ли она.
