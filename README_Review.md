## Замечания / риски
- **Несостыковка про хранение `API_KEY`**: в README написано «ключ в `.xcconfig`», при этом код читает `API_KEY` через `Info.plist` (`Bundle.main.object(forInfoDictionaryKey:)`). Это может быть корректно (через подстановку `$(API_KEY)` в plist), но в README стоит **описать цепочку**: где именно прописывать значение, как оно попадает в `Info.plist`, и что будет при отсутствии.
- **Нет секции “Как запустить”**:
  - Где взять/как задать `API_KEY`.
  - Как собрать проект, какие схемы/минимальная iOS, как запустить тесты.
  - Что делать при первом запуске без сети (ожидаемое поведение).
- **Offline-first заявлен как ключевая фича**, но нет описания ограничений:
  - Что происходит с офлайн‑созданными/изменёнными транзакциями при восстановлении сети.
  - Как решаются конфликты (если не решаются — честно описать).
- **Локализация**: в коде встречаются строки “вшитые” на русском/английском, а `Localizable.xcstrings` содержит много пустых ключей. В README можно кратко упомянуть статус локализации/план.
