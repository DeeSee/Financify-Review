# String+Localized.swift — Code Review

## Замечания

### 1. Рассинхронизация с системой локализации SwiftUI
В SwiftUI-экранах строки часто задаются как `"Загрузка..."`, `"Синхронизация..."`, `"Оффлайн-режим"` — захардкоженные русские строки, минуя `.localized` и `LocalizationManager`. Расширение `.localized` используется в единственном месте — `backButtonTitle` в `AnalysisViewController`.

Фактически система локализации через `LocalizationManager` и `String.localized` не работает для 99% интерфейса. Все строки либо захардкожены по-русски, либо используют `Localizable.xcstrings` (который SwiftUI подхватывает через `Text("key")`).

**Рекомендация:** Определиться с единым подходом к локализации и применить его ко всем строкам.
