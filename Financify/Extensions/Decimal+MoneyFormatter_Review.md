# Decimal+MoneyFormatter.swift — Code Review

## Замечания

### 1. Глобальная переменная `decimalFormatter` (строка 3)
`let decimalFormatter: NumberFormatter` — глобальная переменная на уровне модуля. Это:
- Загрязняет глобальное пространство имён.
- `NumberFormatter` не потокобезопасен — одновременное использование из разных потоков может вызвать гонку данных.

**Рекомендация:** Вынести внутрь расширения как `static let` или создавать при каждом вызове.

### 2. Захардкоженная локаль `ru_RU` (строка 8)
Форматирование всегда в русской локали. Если приложение поддерживает английскую локализацию (а судя по `LocalizationManager` — поддерживает), разделитель групп и формат числа могут быть непривычны для англоязычных пользователей.

### 3. `maximumFractionDigits = 0` (строка 6)
Дробная часть суммы всегда отбрасывается. Для валюты это может быть неприемлемо (например, $10.50 → "10"). Если суммы всегда целые — ок, но это не документировано.
