# Currency.swift — Code Review

## Баги

### 1. `fatalError` в `init(jsonTitle:)` (строка 27)
```swift
default: fatalError("Неподдерживаемая валюта \(jsonTitle)")
```
Если сервер вернёт новую валюту (например, `"GBP"`, `"CNY"`) или невалидную строку, приложение **крашится**. Это происходит в нескольких ViewModel'ах при обработке ответа сервера.

**Рекомендация:** Либо сделать init failable (`init?(jsonTitle:)`), либо бросать ошибку, либо возвращать fallback-значение.

## Замечания

### 2. `rawValue` — символ валюты, а не код
```swift
case rub = "₽"
case usd = "$"
case eur = "€"
```
`rawValue` — это символ, а `jsonTitle` — ISO-код. Это путает: `currency.rawValue` возвращает `"₽"`, а не `"RUB"`. Обычно `rawValue` для enum содержит каноническое значение (код). Стоит поменять местами или переименовать.

### 3. `currencyTitle` — захардкоженные русские строки (строки 7–11)
Не используется система локализации. При смене языка на английский пользователь увидит "Российский рубль ₽".
