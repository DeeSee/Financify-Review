# Direction.swift — Code Review

## Замечания

### 1. Именование `outcome` вместо `expense` (строка 3)
```swift
case outcome
```
В финансовом контексте «outcome» (результат) — это не то же, что «expense» (расход). Правильный английский термин: `expense` или `expenditure`. По всему проекту используется `outcome`, что может путать англоязычных разработчиков.

### 2. Захардкоженные русские строки (строки 9, 12, 20, 23)
`title` и `tabTitle` возвращают русские строки напрямую, минуя систему локализации.

### 3. `title` — «Доходы сегодня» / «Расходы сегодня» (строки 9, 12)
Слово «сегодня» в заголовке — семантическая ошибка: `Direction` не знает о периоде, это ответственность ViewModel'а. `Direction` не должен содержать информацию о временном контексте.
