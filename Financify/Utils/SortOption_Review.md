# SortOption.swift — Code Review

## Замечания

### 1. `iconName` привязан к рублю (строки 14–15)
```swift
case .amountDescending: return "rublesign.circle"
case .amountAscending:  return "rublesign.circle.fill"
```
Иконки сортировки по сумме используют символ рубля. Если пользователь выбрал доллар или евро, иконка будет неконсистентна.

**Рекомендация:** Использовать нейтральные иконки (например, `"arrow.up.circle"`, `"arrow.down.circle"`) или динамически подставлять символ валюты.

### 2. `rawValue` — русские строки
`rawValue` используется одновременно как идентификатор и как отображаемый текст. Если потребуется локализация, `rawValue` придётся менять, что сломает сериализацию (если она есть).
