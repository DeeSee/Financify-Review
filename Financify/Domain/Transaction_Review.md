# Transaction.swift — Code Review

## Замечания

### 1. `convertToTransactionRequest()` — `comment ?? ""` (строка 22)
При конвертации `nil`-комментарий заменяется на пустую строку. Это может привести к тому, что при обновлении транзакции сервер получит пустой комментарий вместо отсутствующего. Семантика может отличаться на стороне API.

### 2. `Equatable` conformance (строка 3)
`Transaction` соответствует `Equatable` через автосинтез, который сравнивает **все** поля, включая `createdAt` и `updatedAt`. Это значит, что две транзакции с одинаковым содержанием, но разным `updatedAt` будут неравны. Для UI-сравнений (например, `animation(.value:)`) это может вызвать лишние перерисовки.

### 3. Несоответствие формата `amount` при encode
Для кодирования используется `NSDecimalNumber(decimal: amount).stringValue` (строка 83), а в `BankAccount` — `String(describing:)`. Нет единого подхода в проекте.
