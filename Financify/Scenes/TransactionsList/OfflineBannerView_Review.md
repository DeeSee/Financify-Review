# OfflineBannerView.swift — Code Review

## Замечания

### 1. Нет `safe area` отступа снизу
Баннер рендерится в самом низу экрана (через `.overlay(alignment: .bottom)`), но не учитывает safe area. На iPhone с home indicator текст может перекрыться.

### 2. Захардкоженная русская строка
`"Оффлайн-режим"` — не локализована.

### 3. Нет возможности dismiss
Баннер показывается, пока устройство оффлайн. Нет кнопки «Повторить» или способа взаимодействия.
