# AppModelContainer.swift — Code Review

## Замечания

### 1. `fatalError` при невозможности создать контейнер (строка 17)
```swift
} catch {
    fatalError("Could not create ModelContainer: \(error)")
}
```
Если SwiftData не может создать контейнер (например, из-за ошибки миграции схемы), приложение крашится без возможности восстановления. Лучше показать пользователю ошибку или попробовать удалить и пересоздать хранилище.

### 2. `@MainActor` на классе (строка 3)
`AppModelContainer` помечен `@MainActor`, но `shared` — это `static let`, который вычисляется лениво при первом обращении. Если первое обращение произойдёт не с main thread, поведение зависит от версии Swift.
